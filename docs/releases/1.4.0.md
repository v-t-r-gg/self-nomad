# self-nomad 1.4.0

Feature release. Schema 1, `--json` envelopes, `self-nomad-pack-v1`, and the
seven MCP tools are unchanged. Tags `v1.3.0`, `v1.2.0`, `v1.1.1`, and
`v1.1.0` are not rewritten.

## Install

```bash
pip install 'self-nomad[tui,gui,mcp,hub]'
self-nomad --version   # expect 1.4.0
self-nomad tui --repo ./agent
self-nomad gui --repo ./agent
```

`[gui]` and `[hub]` add no third-party toolkit. The core wheel still does
not depend on Textual.

## What changed

- `codex`, `cursor`, and `copilot` are thin wrappers over `agents-md`. They
  do not merge extra instruction files into `AGENTS.md`.
- `self-nomad gui` is a loopback HTML operator loop over the same services.
- `self-nomad hub pull` runs `pack --check` before `install`.
  `hub publish` writes a checked specialist pack for a human to commit in
  the registry. It does not upload, and it refuses a personal pack unless
  `--yes-personal` is set.

# self-nomad 1.1.0

Compatible pack-contract release. Schema 1, `--json` envelopes, and the seven
MCP tools are unchanged. There is no hub client in this CLI.

## Install

GitHub Release assets are the beta channel. PyPI publish is optional and is
not required to use 1.1.0.

```bash
pip install self_nomad-1.1.0-py3-none-any.whl
self-nomad --version   # expect 1.1.0
```

Rebuild locally with `python scripts/build_release.py`. That writes the wheel,
sdist, and `SHA256SUMS`. Tagged GitHub Actions builds attest the wheel. A
local rebuild records checksums and signs with GPG only when a key is configured.

```bash
gh attestation verify self_nomad-1.1.0-py3-none-any.whl --repo v-t-r-gg/self-nomad
```

## What changed

- Pack sidecar schema is frozen and exported (`self-nomad-pack-v1.schema.json`), including `packer_version`.
- `pack --check` and `install` fail closed on path escape, planted Git history, links, archive bombs, secrets, policy oversize, digest mismatch, and specialist leakage of user or daily memory.
- Specialist long-term memory, when requested, is only `memory/PUBLISH.md`. `memory/MEMORY.md` is never a specialist pack member.
- `content_digest` is computed from LF-normalized UTF-8 text.
- `pack --check --json` exposes profile, omitted classes, digest, skills, and packer version for an indexer.
- `operator_acceptance.py` covers pack, check, install, and restore into Hermes and OpenClaw directories from the installed wheel.

## Registry boundary

A separate registry consumes `pack`, `pack --check`, `install`, `validate --strict`, and `restore`. It does not receive proposal receipts or working Git history. See [snapshot.md](../snapshot.md) and [ecosystem.md](../ecosystem.md).

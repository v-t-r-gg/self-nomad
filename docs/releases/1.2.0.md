# self-nomad 1.2.0

Feature release. Schema 1, `--json` envelopes, `self-nomad-pack-v1`, and the
seven MCP tools are unchanged. Tags `v1.1.1` and `v1.1.0` are not rewritten.

## Install

```bash
pip install 'self-nomad[tui]'
self-nomad tui --repo ./agent
```

The core wheel does not include Textual. `self-nomad tui` without the extra
prints `pip install 'self-nomad[tui]'` and exits.

## What changed

`self-nomad tui` is a full-screen keyboard loop over the existing services:
home status, detect, import preview (proposal only), review (approve or reject,
never apply), apply on a clean worktree, pack, check, install, and restore
preview then write. It is not a registry client and it does not add MCP tools.

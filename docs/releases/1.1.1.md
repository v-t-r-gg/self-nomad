# self-nomad 1.1.1

Patch release. Schema 1, `--json` envelopes, `self-nomad-pack-v1`, and the
seven MCP tools are unchanged. Tag `v1.1.0` is not rewritten.

## Install

```bash
pip install self_nomad-1.1.1-py3-none-any.whl
self-nomad --version   # expect 1.1.1
```

Rebuild locally with `python scripts/build_release.py`. Tagged GitHub Actions
builds attest the wheel.

## What changed

`pack --check` and `install` recompute `self.id`, `self.name`,
`self.description`, and skill names from the archived tree. A sidecar that
disagrees is rejected. `content_digest` does not cover the sidecar, so
rewriting those fields used to leave `pack --check` valid.

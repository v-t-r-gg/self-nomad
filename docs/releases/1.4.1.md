# self-nomad 1.4.1

Patch release. Schema 1, `--json` envelopes, `self-nomad-pack-v1`, and the
seven MCP tools are unchanged. Tag `v1.4.0` is not rewritten.

## Install

```bash
pip install 'self-nomad[tui,gui,mcp,hub]'
self-nomad --version   # expect 1.4.1
```

## What changed

- self-nomad does not host, search, or authenticate to an index.
  `hub publish` writes a checked `.snpack` for a human pull request.
  `hub pull` runs `pack --check`, then `install`. The registry stores files
  and `index.json`. It has no upload API.
- A relative pack path in an `https` index is joined to that index URL's
  directory. `..` is refused. `pack --check` still runs before install.

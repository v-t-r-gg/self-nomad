# self-nomad 1.3.0

Feature release. Schema 1, `--json` envelopes, `self-nomad-pack-v1`, and the
seven MCP tools are unchanged. Tags `v1.2.0`, `v1.1.1`, and `v1.1.0` are not
rewritten.

## Install

```bash
pip install self_nomad-1.3.0-py3-none-any.whl
self-nomad --version   # expect 1.3.0
```

The TUI stays an extra: `pip install 'self-nomad[tui]'`.

## What changed

- `agents-md` detects a project workspace that has `AGENTS.md` or a `skills/`
  tree. Instructions are adapted. `.env` and vendor state stay excluded.
- `claude-code` is a separate adapter. `CLAUDE.md` wins over `AGENTS.md`.
  The files are not merged. `AGENTS.md` is the fallback only when `CLAUDE.md`
  is absent. Restore writes `CLAUDE.md`.

# self-nomad 0.2.0rc1

Operator-acceptance release candidate. This is a **pre-release**.

## What to install

Attach the GitHub Release assets (wheel, sdist, `SHA256SUMS`). After download:

```bash
sha256sum -c SHA256SUMS
pip install self_nomad-0.2.0rc1-py3-none-any.whl
self-nomad --version   # expect 0.2.0rc1
```

On a tagged GitHub-built artifact, verify provenance:

```bash
gh attestation verify self_nomad-0.2.0rc1-py3-none-any.whl --repo v-t-r-gg/self-nomad
```

Local rebuilds write `SHA256SUMS` and may add `SHA256SUMS.asc` when GPG is
configured. Attestations are produced by the tag workflow, not by a laptop
rebuild.

## Operator acceptance

The candidate is ready when all of the following hold on a **non-editable**
wheel install:

- `self-nomad --version` matches the artifact name and package metadata
- `init` → `validate --strict` succeeds
- propose → validate → approve → apply updates the target branch
- `intake` preview/submit materializes a proposal and does not approve
- `restore` without `--yes` does not write the runtime tree
- A schema 1 repository created under the first public RC still validates

Harness: `uv run python scripts/operator_acceptance.py` after
`uv run python scripts/build_release.py`.

## Upgrade from 0.1.0rc1

Schema version stays 1. Install the new wheel over the previous one and run
`validate --strict` on existing repositories. See [upgrading.md](../upgrading.md).

## Not in this candidate

- Public registry hosting or hub-client commands
- Snapshot pack/install commands (ADR 0007; consumed later by
  [portable-agent-registry](https://github.com/v-t-r-gg/portable-agent-registry))
- Remote MCP transports
- PyPI publish (optional, after operator sign-off)

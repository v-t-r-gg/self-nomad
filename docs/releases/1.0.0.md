# self-nomad 1.0.0

Stable release. Schema 1, `--json` envelopes, and the MCP allow-list are
compatibility promises ([compatibility.md](../compatibility.md)).

## What to install

```bash
sha256sum -c SHA256SUMS
pip install self_nomad-1.0.0-py3-none-any.whl
self-nomad --version   # expect 1.0.0
```

Tagged GitHub artifacts carry SLSA provenance:

```bash
gh attestation verify self_nomad-1.0.0-py3-none-any.whl --repo v-t-r-gg/self-nomad
```

TestPyPI / PyPI publish is optional and separate from the GitHub Release.

## Operator loop

```bash
self-nomad about
self-nomad init ./agent --name demo
self-nomad --repo ./agent propose --reason "…" --change change.yaml
self-nomad --repo ./agent review PROPOSAL_ID --interactive
self-nomad --repo ./agent apply PROPOSAL_ID
self-nomad --repo ./agent pack --out ./demo.snpack
self-nomad install ./demo.snpack --to ./demo-copy
```

## Not in 1.0

- Public registry hosting or hub-client commands
- Remote MCP
- Automatic approval
- A third product runtime adapter (`example-files` is a kit sample only)
